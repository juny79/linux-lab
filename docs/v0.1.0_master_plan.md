# [v0.1.0] 리눅스 엔지니어 실무 시나리오 학습 플랫폼 종합계획서

> **버전**: v0.1.0  
> **작성일**: 2026-11-22  
> **상태**: 아카이브 (v0.2.0에서 B2C 및 온프레미스 환경으로 구체화됨)

## 1. 프로젝트 비전
단순 명령어 암기가 아닌, 실제 출근해서 장애를 해결하고 의사결정하는 **리얼리티 실무 시뮬레이터**.
- 가상 사내 메신저(Slack), 이슈 트래커(Jira), 모니터링 대시보드(Grafana), 실제 리눅스 멀티 노드 터미널 통합 제공
- 커리어 전 주기(주니어 → 중니어 → 시니어 → C레벨) 지원

## 2. 레벨별 커리큘럼 요약
- **Junior (0~2년차)**: 디스크 Full, systemd 장애, 권한/방화벽, 로그 분석 (단일 VM)
- **Mid-level (3~5년차)**: HAProxy/Keepalived HA, LVM/RAID, Ansible 자동화, 모니터링/sysctl 튜닝 (멀티 노드)
- **Senior (6~10년차)**: eBPF/perf 병목 추적, OOM Killer, 침해 사고 포렌식, K8s 노드 트러블슈팅 (복합 클러스터)
- **C-Level (VP/CTO/CISO)**: 대규모 리전 장애 DR 의사결정, TCO 분석, 위기관리 Tabletop 시뮬레이터

## 3. 기본 시스템 아키텍처 방향
- **Frontend**: Next.js + xterm.js + 가상 사내 도구 UI
- **Backend**: Go(오케스트레이션/WS) + Python/FastAPI(AI/채점)
- **Sandbox**: Kubernetes + Firecracker/Kata Containers 기반 MicroVM 격리
- **Evaluation**: Goss/InSpec 상태 검증 + 명령어 로그/포스트모템 AI 평가
